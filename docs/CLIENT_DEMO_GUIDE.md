# Client Demo Guide (5–7 minutes)

Start from **Overview → Guided demo** (or the button in the top bar). If the browser has custom work, choose **Keep my work** or **Reset & start** (reset asks first and lists what will be replaced). The demo bar sits at the bottom: progress dots, Previous / Next / Restart / Exit, presenter cues and direct links. **Alt + ← / →** changes scene (ignored while typing). Nothing is modal; the app stays fully clickable.

| # | Scene | Where | Show |
|---|---|---|---|
| 1 | Brand intelligence | Brand DNA | Approved v3, palette with signature colours, rules vs exclusions, approval workflow |
| 2 | Generate concepts | Studio | “Oversized blazer” example → Brand mode → request preview → Generate 4 → inspector brand consistency |
| 3 | Refine a design | Editor (`cpt_01`) | v1/v2 timeline, annotations, Refine “Use linen instead of wool”, compare slider, Brand tab |
| 4 | Build a collection | AW26 board → Present | Reorder, notes, submit/approve a look, presentation (←/→, N, Esc) |
| 5 | Preview & handoff | Try-on → Technical → Pilot | Conceptual fitting preview (labelled), brief prefilled from metadata, edit measurements (cm/in), Export PDF, pilot readiness |

**Talking points:** brand learning is profile conditioning + rule checks (no training); every AI result is labelled Simulated; versions are never overwritten; try-on is conceptual; the brief is concept-stage.

**Reset:** Pilot Readiness → Reset demo (confirms first). Curated data: Serein Atelier, two collections, `cpt_01` with v1/v2, annotations, review history, a technical brief and three saved previews.
