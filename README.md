# RACO AI Fashion Studio — client demo

Interactive proof-of-concept for an AI-assisted fashion design studio. Frontend only; every AI result is a clearly labelled **Simulated** fixture.

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint && npm run typecheck && npm test && npm run build
```

Optional flags: `NEXT_PUBLIC_FLAG_TRY_ON`, `NEXT_PUBLIC_FLAG_TECHNICAL`, `NEXT_PUBLIC_FLAG_DEMO` (set to `false` to hide).

Client demo: open the app → **Guided demo**. See [docs/CLIENT_DEMO_GUIDE.md](docs/CLIENT_DEMO_GUIDE.md).
